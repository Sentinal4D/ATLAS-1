ATLAS-1: 3D Drug-Treated Cancer Cells

1,500 single-cell point clouds from WM266-4 melanoma embedded in collagen and imaged with oblique-plane light-sheet microscopy. Includes Nocodazole, Blebbistatin, and Control conditions.

Information

Summary

ATLAS-1 provides 3D cell morphologies under drug treatment for benchmarking point-cloud methods and studying shape changes. Each cell is represented as a 1024-point cloud sampled from a reconstructed surface mesh.

  • Cells: 1,500 (500 per condition)
  • Conditions: Nocodazole (rounding), Blebbistatin (elongation), Control (baseline variability)
  • Pipeline: segmentation → marching cubes + Laplacian smoothing → 1024-point sampling

Access

  • Hugging Face dataset: Open on HF
  • Metadata: metadata.csv with labels & experimental details
  • Loaders: Python utilities for reading point clouds & meshes

Cite the PointMIL paper when using this dataset. See license details on the dataset page.
